# Bailanysta

Простое приложение-соцсеть: можно публиковать посты и видеть их в общей ленте.

## Описание проекта

Тестовое задание — минимальная соцсеть с созданием постов, лентой и переходом между страницами (лента / профиль). Проект сделан на Next.js: фронтенд и бэкенд находятся в одном приложении. Данные хранятся в базе данных Postgres.

## Стек технологий

- **Next.js** (App Router) — фреймворк, объединяющий фронтенд и бэкенд в одном проекте
- **React** — для интерактивности интерфейса (форма, лента постов, лайки, поиск)
- **Tailwind CSS** — для стилизации, включая поддержку тёмной/светлой темы
- **Postgres (Neon, через Vercel Storage)** — база данных для хранения постов
- **TypeScript** — не использовался, проект написан на обычном JavaScript/JSX ради простоты (это был мой первый опыт в разработке)

## Функциональность

- Создание постов и лента
- Переключение между главной страницей и страницей профиля
- Лайки на постах
- Поиск по постам
- Тёмная/светлая тема
- Скелетоны при загрузке ленты

## Как это устроено

- `app/page.tsx` — главная страница: форма создания поста, поиск, лента постов
- `app/profile/page.tsx` — страница профиля
- `app/api/posts/route.ts` — собственный API (бэкенд): `GET` отдаёт список постов, `POST` добавляет новый пост, `PATCH` увеличивает счётчик лайков — все запросы к базе данных выполняются здесь, на сервере

## Установка и запуск локально

\`\`\`bash
git clone https://github.com/nilovichwork/bailanysta.git
cd bailanysta
npm install
\`\`\`

Для подключения к базе данных нужен файл `.env.local` с переменной `DATABASE_URL` (не хранится в репозитории по соображениям безопасности). Получить его можно через Vercel CLI:

\`\`\`bash
vercel link
vercel env pull .env.local
\`\`\`

Затем запустить сервер разработки:

\`\`\`bash
npm run dev
\`\`\`

Открыть в браузере: http://localhost:3000

## Процесс разработки

Так как я до этого не программировал(а), разработка шла пошагово:
1. Создание проекта Next.js
2. Вёрстка формы создания поста и ленты постов
3. Добавление интерактивности через React (useState)
4. Создание собственного API-роута для хранения постов
5. Подключение фронтенда к API через fetch
6. Добавление второй страницы (профиль) и роутинга между страницами
7. Деплой на Vercel
8. Добавление бонусных фич: тёмная/светлая тема, лайки, скелетоны, поиск
9. Подключение настоящей базы данных Postgres вместо временного хранения в памяти сервера (для надёжного сохранения данных на serverless-платформе)

## Выбор стека и компромиссы

- **Next.js** выбран, чтобы не разворачивать отдельный бэкенд-сервер — фронтенд и API живут в одном проекте
- **Postgres через Vercel Storage** — выбран после того, как выяснилось, что хранение постов "в памяти" ненадёжно на serverless-платформе Vercel (данные сбрасывались между запросами); переход на настоящую БД занял немного больше времени, но сделал приложение стабильным
- **Без TypeScript** — упростило вход в разработку, так как я делал(а) это в первый раз

## Известные баги / ограничения

- Нет валидации длины текста поста
- Нет аутентификации — все посты публикуются от имени "Ты"
- Не реализованы подписки/уведомления и AI-генерация контента (не входили в приоритетные бонусы)
